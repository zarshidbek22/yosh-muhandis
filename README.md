# Yosh Muhandis — рабочий прототип

Платформа для школьников: уроки с проверкой задания, конкурсы и лига, комиксы-миссии, портфолио, магазин работ учеников и кабинет родителя.

Сайт статический (HTML, CSS, JS), сервер не нужен. Все данные демонстрационные и хранятся только в браузере зрителя. Реальной оплаты нет.

Запуск локально: `python -m http.server` в этой папке, затем http://localhost:8000.
